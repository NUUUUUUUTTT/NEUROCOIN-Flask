# NEUROCOIN — Flask

> Система учебной валюты для управления успеваемостью студентов.

---

## Быстрый старт

Перед запуском установите зависимости:

```bash
pip install flask
```

---

## Доступ и управление
**Структура без архива(файлами)
- Папка NEUROCOIN -> Файл app.py + Файл neurocoin.db + Папка public -> Папка public
  -> Файл index.html

---
**Вход для учителя:**
- Логин: `Teacher`
- Пароль: `TeacherSmotrit`

**Студенты** регистрируются самостоятельно через кнопку «Регистрация» на главном экране. При регистрации вводятся: фамилия, имя, отчество, группа, логин и пароль.

---

## Правила системы

- Студент выбирает тему и оценку (3, 4, 5, зачёт) → отправляет запрос
- NC списываются **только после одобрения учителем**
- Если NC не хватает — кнопка неактивна
- Учитель может вручную начислять и списывать NC с указанием причины
- Все операции отображаются в истории у студента и в логе у учителя

---

## Адаптация под себя

Проект легко настраивается под любую организацию:

- **Название** — смените на своё
- **Валюта** — замените NC на любую другую единицу вознаграждения
- **Стиль** — настройте оформление под свой бренд

> Достаточно ~10 минут работы с кодом.
